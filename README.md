# Final Bell — 3D boxing simulator (Godot)

Проект восстановления, доработки и подготовки к публикации боксерского симулятора **Final Bell**.

> **Статус на 21.11.2026:** GitHub-репозиторий создан, исходники пока не восстановлены. Подтверждён лишь существующий Windows-экспорт на скриншоте пользователя: `Final Bell.exe` и `Final Bell.pck`. Наличие и содержимое этих файлов внутри ZIP ещё **не проверено**.

## Где материалы

- **Архив владельца:** [Final Bell.zip в Google Drive](https://drive.google.com/file/d/19rWlRQl7qje0Hz0FifdBOq4eKI758d8z/view?usp=drive_link), **664 878 653 байта** (≈ 634 MiB).

- **Контекст и план для следующего чата:** [PROJECT_STATE.md](PROJECT_STATE.md)

Google Drive сообщает, что архив не имеет общего доступа (доступен владельцу через подключённый аккаунт). Подключённый инструмент не смог скачать файл: 664,9 МБ превышает его лимит 256 МБ. Это **не** означает, что ZIP повреждён или что восстановление невозможно.

## Задача

1. Получить и исследовать содержимое ZIP без потери оригинального экспорта.
2. Если внутри только `.exe`/`.pck`, попробовать восстановление ресурсов и скриптов через [GDRETools](https://github.com/GDRETools/gdsdecomp); проверить лицензионность и происхождение ассетов.
3. Собрать **открываемый в Godot проект**, определить фактическую версию движка, запустить, устранить проблемы импорта.
4. Исправить управление боксом, отклик ударов, анимации и проблемные Blender-ассеты; проверять изменения игровым тестом.
5. После реального тестирования выбрать релиз и монетизацию для Windows, в первую очередь рассмотреть VK Play. Не обещать публикацию, пока игра не готова.

## Хранение больших файлов

- Обычный GitHub Git блокирует один файл больше **100 MiB**.
- Для отдельных крупных исходных ассетов можно применять Git LFS (проверять квоты аккаунта).
- Большой ZIP с готовым экспортом лучше оставлять на Drive или прикреплять к GitHub Release, **не коммитить в историю Git**.
- В Git должны быть текстовые сцены/скрипты, конфигурация, документация и ассеты разумного размера; для крупных бинарников — LFS по необходимости.

**Важно:** никаких фактических исходников здесь ещё нет. Не путать намерения в этом README с выполненными работами.
