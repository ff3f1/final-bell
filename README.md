## Инструменты для следующего этапа

Добавлена первичная проверка исходного ZIP без повторной загрузки в чат:

```powershell
python .\tools\inventory.py "C:\Путь\к\Final Bell.zip" --output "$env:USERPROFILE\Desktop\FinalBell_Audit"
```

Скрипт создаёт `inventory.md` и `inventory.json`, считает SHA-256 оригинального архива, определяет наличие Godot-проекта и экспортов. Опция `--extract-packs` отдельно извлекает EXE/PCK, **не запуская их**. Подробные действия для Windows и восстановления через GDRETools: **[docs/RECOVERY_GUIDE.md](docs/RECOVERY_GUIDE.md)**.

Проверки ZIP-инструмента: `python -m unittest discover -s tests -v`. Отдельный анализатор PCK v4 проверен локально на реальном архиве: 1271/1271 MD5; исходная игра пока не запускалась. В метаданных восстановлены `.gdc` и файлы импорта, однако для запуска требуется получить читаемые `.gd` и редактируемые ресурсы.

## Хранение больших файлов

- Обычный GitHub Git блокирует один файл больше **100 MiB**.
- Для отдельных крупных исходных ассетов можно применять Git LFS (проверять квоты аккаунта).
- Большой ZIP с готовым экспортом лучше оставлять на Drive или прикреплять к GitHub Release, **не коммитить в историю Git**.
- В Git должны быть текстовые сцены/скрипты, конфигурация, документация и ассеты разумного размера; для крупных бинарников — LFS по необходимости.

**Важно:** никаких фактических исходников здесь ещё нет. Не путать намерения в этом README с выполненными работами.
